# GeneratePress Utility Documentation

Welcome to the official documentation for **GeneratePress Utility**. This guide provides comprehensive instructions for both end-users and developers to get the most out of our modular utility suite.

---

## 🚀 Quick Start
GeneratePress Utility is a performance-focused companion plugin for the GeneratePress theme. It adds modern design features such as Fluid Typography, Dark Mode, and CSS Synchronization without the bloat.

- **Requirements**: WordPress 6.0+, PHP 7.4+, GeneratePress Theme.
- **License**: GPLv2 or later.

---

## 👥 End-User Guide

### 1. Fluid Typography Wizard
Traditional responsive design requires many media queries. Our Fluid Typography system uses the CSS `clamp()` function to create text that scales smoothly based on the screen size.

**How to use:**
1. Navigate to **Appearance > Utility**.
2. Ensure the **Fluid Typography** module is active.
3. Open the **Customizer > Typography > Fluid Scaling**.
4. Use the **Wizard** to define your base font size and scale ratio.
5. Watch your text scale perfectly from mobile to ultra-wide monitors.

### 2. Native Dark Mode
Enable a modern dark/light mode toggle that integrates seamlessly with your site's design.

**Setup:**
1. In the **Customizer**, go to **Utility > Dark Mode**.
2. Choose your **Toggle Position** (After Nav, Inside Nav, or Floating).
3. Select an **Icon Style** (Outlined, Monocolor, or Multicolor).
4. Customize your **Dark Global Colors** to match your brand's dark aesthetic.

### 3. Editor CSS Sync
Ever get frustrated when your Customizer CSS doesn't show up in the Gutenberg editor? 
- This feature works automatically in the background.
- It syncs your **Additional CSS** and **Child Theme CSS** directly into the block editor canvas.
- No more guessing how your layout will look on the frontend.

## 💻 Developer Documentation

### Architecture Overview
The plugin is built with a strictly modular architecture. Each feature is a standalone class located in the `includes/` directory, managed by the `WPIDS_Utility_Core` class.

- **Namespace/Prefix**: All functions and classes are prefixed with `WPIDS_` or `wpids_`.
- **Performance**: We use zero external dependencies (no jQuery, no heavy frameworks). Logic is handled via Vanilla JS and modern CSS.

### CSS Variables (Tokens)
The plugin generates several dynamic CSS variables that you can use in your own custom CSS or within GenerateBlocks:

| Variable | Description |
| :--- | :--- |
| `--wpids-fluid-[slug]` | Dynamic fluid font size generated by the Typography module. |
| `--[color-slug]` | Overridden global color variables when Dark Mode is active. |
| `--wpids-custom-property` | Any properties defined in the Advanced Raw CSS box. |

### Advanced Raw CSS (The Linter Bypass)
WordPress Customizer sering kali memblokir fitur CSS modern seperti `@property` atau sintaks Houdini yang kompleks.
- Gunakan kotak **Advanced Raw CSS** di Dashboard Utility untuk menulis gaya ini.
- Gaya ini disanitasi via `wp_strip_all_tags` dan diinjeksi dengan aman ke frontend dan block editor.

### Security Implementation
Kami mengikuti panduan keamanan WordPress yang ketat:
- **Sanitization**: Semua input diproses melalui `sanitize_text_field`, `absint`, atau `map_deep`.
- **Escaping**: Output di-escape menggunakan `esc_html`, `esc_attr`, atau `wp_kses_post`.
- **Permissions**: Semua tindakan admin dilindungi oleh `current_user_can('manage_options')` dan verifikasi Nonce.

## 🛠 Troubleshooting

**Q: Mengapa saya tidak melihat toggle Dark Mode?**
A: Pastikan modul aktif di Dashboard Utility dan Anda telah menetapkan posisi di Customizer.

**Q: Apakah kompatibel dengan GenerateBlocks?**
A: Ya! Warna global dan gaya lokal GenerateBlocks menghormati variabel CSS yang dikelola oleh plugin ini.
